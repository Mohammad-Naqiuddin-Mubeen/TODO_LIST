## Description
The TODO List App is a React-based application designed to help users manage their tasks efficiently. With a clean interface, users can add, edit, and delete their tasks, making it an essential tool for productivity.

## Features
- **Add Tasks:** Quickly add new tasks to your list.
- **Edit Tasks:** Update existing tasks with ease.
- **Delete Tasks:** Remove tasks that are no longer needed.

## Technologies Used
- **React:** For building user interfaces.
- **JavaScript:** Core programming language.
- **CSS:** For styling the application.
- **State-Management:** To persist tasks.
